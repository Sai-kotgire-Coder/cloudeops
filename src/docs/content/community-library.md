# Community Library

Beyond the official docs (the guides in this sidebar), CloudOps Simulator has a community-driven library — documentation, research papers, and blog posts submitted by other users, reviewed by an admin before anyone else can see them.

## Browsing

Open [Community Library](app:/docs/community) to browse everything that's been approved so far, filterable by type (**Documentation**, **Research Paper**, or **Blog**). Click any entry to read the full piece, rendered the same way this page is.

Every approved entry has a **Helpful** button — a simple thumbs-up you can toggle on anything you found genuinely useful — and a comment thread underneath it, so you can ask a follow-up question or add your own perspective directly on someone else's submission.

## Submitting your own

Anything you've learned that might help someone else — a write-up of a concept you finally understood, a mini research summary, a blog-style post about a project — can be submitted from [Submit Content](app:/docs/community/submit). You'll need a title, a type, a short summary, the full content (written in the same markdown you're reading right now, with a live preview before you submit), and optionally a link to something external if your content lives elsewhere too.

## Review, not instant publishing

Every submission starts **pending**. It's only visible to you (on [My Submissions](app:/docs/community/mine)) until an admin reviews it:

- **Approved** — it becomes visible to everyone in the Community Library, and every user gets a notification that new content was published.
- **Rejected** — it stays private to you, along with an optional note from the admin explaining why, so you know what to improve if you want to try again.

This review step exists so the library stays a genuinely useful, accurate resource rather than an unmoderated dump — the same standard the official docs are held to.

## Try it yourself

1. Browse [Community Library](app:/docs/community) and mark something **Helpful** if it actually helps you.
2. Leave a comment on something you have a question or a follow-up thought about.
3. If you've learned something worth sharing, write it up on [Submit Content](app:/docs/community/submit) and check [My Submissions](app:/docs/community/mine) for the review outcome.
